# Phase 2 — Hero to Product Shell

## User experience objective

The start page establishes emotion, trust, personality and brand. Activating
the calculator changes the user's intent from evaluating NOURA to completing a
task. The visual system therefore becomes quieter without changing identity.

## Decisions

### One atmospheric image moment

The portrait remains in the start hero and is removed from every calculator
decision state. Repeating it beside the form would create a second visual task
without adding decision-relevant information.

Derived principle: atmosphere is separate from work.

### A continuous shell, not a scene cut

Header, warm canvas, logo language, spacing scale and surface material remain
continuous. Only the content measure and information density change. This
makes the transition feel like entering a quieter room within the same product.

Derived principles: warmth through materiality; hierarchy before decoration.

### One centered decision axis

Progress, question, choices and actions share the same maximum width. The old
desktop image column and static slogan are removed in work mode. The question
is now the only dominant element.

Derived principles: calm before density; one task per view.

### Restrained hero typography

The desktop headline now uses the official hero token rather than a separate
6.4rem product scale. Mobile retains the proven compact composition and touch
geometry.

Derived principle: typography communicates role, not decoration.

### Explicit action-on-image semantics

The light hero CTA remains because it is the accessible primary action on a
dark image. Its colors are now named by role inside the shell instead of being
anonymous white overrides. Normal product actions remain brown.

Derived principles: accessibility is style; color is semantic.

## Deliberate non-changes

- No form component, label, option, validation or action behavior changed.
- No calculator, safety, guidance, result or planner logic changed.
- Results and weekly planner composition remain outside phase 2.
- No additional image, font, script or network request was introduced.
